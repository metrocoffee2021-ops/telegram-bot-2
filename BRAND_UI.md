# Metropia Coffee — Digital UI System V2

## Core
- White 60% / Black 30% / Red 10%
- White = breathing space
- Black = structure, typography, hierarchy
- Red = attention, CTA, price/highlight
- Typeface: Inter / Inter Display
- Geometry over decoration
- Strong negative space
- Product first
- Avoid excessive emojis, gradients, 3D effects, clutter

## Customer navigation
MENU · CART · REWARDS · MY ORDERS

## Order lifecycle
NEW → PREPARING → READY → COMPLETED

## Brand signature
“Your coffee spot...” is a secondary signature, not a mandatory headline.

## Uzbek
All Uzbek interface copy must use Latin script. Do not introduce Uzbek Cyrillic.
